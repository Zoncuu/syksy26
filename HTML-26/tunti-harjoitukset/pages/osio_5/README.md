# Osio 5 – HTML-listat

Osiossa harjoiteltiin toisiinsa liittyvien asioiden ryhmittelyä semanttisesti oikeanlaisiksi listoiksi.

## Mitä osiossa harjoiteltiin

- järjestämättömät listat
- järjestetyt listat
- kuvaus- eli määritelmälistat
- sisäkkäiset listat
- listojen käyttäminen navigaatiossa
- oikean listatyypin valitseminen sisällön merkityksen mukaan
- listojen muotoileminen CSS:llä rakennetta rikkomatta
- tavallisimpien listarakenteen virheiden tunnistaminen

## Keskeiset elementit

`ul`, `ol`, `li`, `dl`, `dt` ja `dd`

## Harjoitustiedostot

Tässä kansiossa ei ole vielä erillistä HTML-harjoitustiedostoa. Listoja käytetään kuitenkin myös muiden osioiden sivuilla.

## Osaamistavoite

Osion jälkeen opiskelija osaa valita sisällölle oikean listatyypin ja rakentaa myös sisäkkäisiä ja saavutettavia listarakenteita.
